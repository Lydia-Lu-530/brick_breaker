                                        打砖块游戏 — C++ Raylib 项目
本项目是基于 C++ + Raylib 开发的经典打砖块游戏，包含菜单系统、多关卡、存档读档、道具系统、粒子特效、JSON关卡配置等完整功能。
1. 游戏功能
~ 主菜单：开始新游戏、继续游戏、选择关卡
~ 3个关卡：难度递增，布局由 JSON 配置
~ 存档读档：按 E 自动保存，下次可继续进度
~ 道具系统：挡板延长、多球、减速球
~ 粒子特效：砖块破碎动画
~ 计分与生命：实时分数、生命值显示
~ 清晰 UI：关卡、分数、生命值、操作提示
~ 排行榜：简单排行榜展示

3. 操作说明
① 菜单界面
    1 — 新游戏
    2 — 继续游戏
    3 — 选择关卡
    ← / → — 切换关卡
    Enter — 确认选择
    L — 查看排行榜
② 游戏界面
    ← / → — 移动挡板
    P — 暂停 / 继续
    E — 保存并返回菜单
4. 关卡设计
关卡由 JSON 文件定义：
    第 1 关：5 行砖块
    第 2 关：7 行砖块
    第 3 关：9 行砖块
砖块分数：
    金色：50 分
    橙色：20 分
    红色：10 分
5. 存档功能
游戏中按 E 自动保存当前关卡、分数、生命值
菜单选择 “continue” 可恢复进度
存档文件：savegame.json
6. 编译运行
依赖：Raylib、C++11 及以上
终端输入：make clean && make
         make run
